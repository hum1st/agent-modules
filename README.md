---

## Installation

Install [Git](https://git-scm.com/downloads) (on Windows, use **Git Bash** for commands below).

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

Update your local copy:

```sh
git -C ~/.agentBay pull --ff-only
```
