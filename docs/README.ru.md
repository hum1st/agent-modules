---

## Installation

Установите [Git](https://git-scm.com/downloads) (в Windows для команд ниже используйте **Git Bash**).

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

Обновите локальную копию:

```sh
git -C ~/.agentBay pull --ff-only
```
