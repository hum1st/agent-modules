## Installation

<p dir="rtl">ثبّت [Git](https://git-scm.com/downloads) (على Windows، استخدم **Git Bash** للأوامر أدناه).</p>

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

<p dir="rtl">حدّث نسختك المحلية:</p>

```sh
git -C ~/.agentBay pull --ff-only
```
