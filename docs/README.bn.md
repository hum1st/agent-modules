## Installation

[Git](https://git-scm.com/downloads) ইনস্টল করুন (Windows-এ, নীচের কমান্ডগুলোর জন্য **Git Bash** ব্যবহার করুন)।

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

আপনার স্থানীয় কপি হালনাগাদ করুন:

```sh
git -C ~/.agentBay pull --ff-only
```
