## Installation

[Git](https://git-scm.com/downloads) इंस्टॉल करें (Windows पर, नीचे दिए गए कमांड के लिए **Git Bash** का उपयोग करें)।

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

अपनी स्थानीय प्रति अपडेट करें:

```sh
git -C ~/.agentBay pull --ff-only
```
