---

## Installation

安装 [Git](https://git-scm.com/downloads)（在 Windows 上，请使用 **Git Bash** 执行下方命令）。

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

更新本地副本：

```sh
git -C ~/.agentBay pull --ff-only
```
