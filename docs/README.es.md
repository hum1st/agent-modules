---

## Installation

Instala [Git](https://git-scm.com/downloads) (en Windows, usa **Git Bash** para los comandos siguientes).

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

Actualiza tu copia local:

```sh
git -C ~/.agentBay pull --ff-only
```
