---

## Installation

Installez [Git](https://git-scm.com/downloads) (sous Windows, utilisez **Git Bash** pour les commandes ci-dessous).

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

Mettez à jour votre copie locale :

```sh
git -C ~/.agentBay pull --ff-only
```
