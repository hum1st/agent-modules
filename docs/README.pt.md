---

## Installation

Instale o [Git](https://git-scm.com/downloads) (no Windows, use o **Git Bash** para os comandos abaixo).

```sh
git clone https://github.com/hum1st/agent-bay.git ~/.agentBay
```

Atualize a sua cópia local:

```sh
git -C ~/.agentBay pull --ff-only
```
